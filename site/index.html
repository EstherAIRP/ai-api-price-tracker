DATA TRANSPARENCY

資料如何取得？

平台 API 報價：直接讀取 OpenRouter 提供的模型計價資料；若該來源拒絕存取，系統會保留前次有效值並顯示過期狀態。

社群彙整參考：其餘供應平台使用 Models.dev 公開資料。標示「官方通路」代表可向開發商直接購買，不代表已從官方價格頁逐項查核。

OpenRouter 方案換算：切換 Standard／Business 時，OpenRouter 價格依儲值手續費率換算為含費參考價（原牌價 × 1.055／1.08），並以驚嘆號提示；非逐筆推論另外收費。Standard 單次儲值最低收費 $0.80，小額儲值的實際負擔可能較高。其他平台維持蒐集牌價。此政策資料為人工核對快照，非每日自動核實。OpenRouter 官方定價。

上下文限制：使用各平台模型目錄提供的上下文長度，與最大輸出 Token 分別保存。OpenRouter 路由可能切換供應商，顯示值屬目錄參考限制，不代表所有路由都保證相同；來源缺值則顯示「—」。

每天自動更新：09:00 蒐集、12:00 發布；來源失敗或異常價格不會覆蓋有效舊值。個別供應商的批次、快取及促銷費率可能不同，實際購買前應點選官網核對。
