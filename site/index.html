DATA TRANSPARENCY

資料如何取得？

平台 API 報價：直接讀取 OpenRouter 提供的模型計價資料；若該來源拒絕存取，系統會保留前次有效值並顯示過期狀態。

社群彙整參考：其餘供應平台使用 Models.dev 公開資料。標示「官方通路」代表可向開發商直接購買，不代表已從官方價格頁逐項查核。

平台手續費：手續費採獨立政策資料，記錄最近人工核對日期；模型價格每日更新不代表平台費率也已每日核實。OpenRouter 官方定價。

每天自動更新：09:00 蒐集、12:00 發布；來源失敗或異常價格不會覆蓋有效舊值。個別供應商的批次、快取及促銷費率可能不同，實際購買前應點選官網核對。
